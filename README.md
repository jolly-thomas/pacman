# Pac-Man

A simple Pac-Man clone built in Java using Swing and Gradle.

## Features

* Classic Pac-Man movement and controls
* Random ghost movement
* Collision detection with walls and ghosts
* Food collection and score tracking
* Life system and game reset functionality
* Sound effects
* Keyboard controls using Swing key bindings

## Controls

| Key   | Action     |
| ----- | ---------- |
| Space | Start Game |
| ↑     | Move Up    |
| ↓     | Move Down  |
| ←     | Move Left  |
| →     | Move Right |

## Technologies Used

* Java 21
* Swing
* Gradle

## Running the Project

Clone the repository:

```bash
git clone https://github.com/jolly-thomas/pacman.git
```

Navigate to the project directory:

```bash
cd pacman
```

Run the application:

```bash
./gradlew run
```

or run the `Main` class directly from your IDE.
